🏗️ Core Backend Specifications:

Django REST Framework API: Acts as the central communication hub between the React frontend and all backend services.

Custom User Model: Differentiates between community "Citizens" and council "Admins" to manage granular permissions.

PostgreSQL with PostGIS: Stores and queries geospatial data to handle map-based reporting and location logic.

Azure Blob Storage: Offloads high-resolution image storage to a secure cloud environment in the UAE North region.

🎨 Core Frontend Specifications:

React + Vite Framework: Provides a high-performance, reactive UI for a smooth user experience on all devices.

Progressive Web App (PWA): Enables mobile installation and offline capabilities for reporting issues in low-connectivity areas.

Google Maps JS API: Renders an interactive map interface for pinning issue locations and viewing repair hotspots.

Browser Geolocation: Automatically captures real-time GPS coordinates to simplify the user reporting process.

Tailwind CSS UI: Ensures a mobile-first, responsive design that is accessible to all community members.

Direct-to-Cloud Upload: Uses SAS tokens to upload images directly to Azure, reducing server bandwidth usage.

🧠 Intelligent & Cultural Features:

Spatial Deduplication: Automatically clusters reports within a 50-meter radius to prevent duplicate maintenance tickets.

GPS EXIF Extraction: Automatically identifies coordinates by reading metadata from uploaded facility photos.

Google Maps Geocoding: Converts raw GPS coordinates into verified, human-readable street addresses for repair crews.

MCP Cultural Guardian: Cross-references report locations with Wāhi Tapu databases to protect culturally sensitive sites.

PII Redaction Engine: Locally strips personally identifiable information before data is processed by cloud-based AI.

Anonymous Participation: Removes barriers to entry by allowing citizens to report issues without creating an account.

🛡️ Security & Infrastructure:

GitHub Actions CI/CD: Automates the build and deployment process to Azure Kubernetes Service (AKS).

Kubernetes Secret Management: Injects sensitive database and API credentials securely into the application pods.

Environment-Driven Config: Maintains clear separation between development and production settings using .env variables.

TLS/SSL Encryption: Ensures all data in transit between the user, the API, and the database is fully encrypted.
